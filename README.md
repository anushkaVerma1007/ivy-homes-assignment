# Ivy Homes Assignment

A web application developed as part of the **Ivy Homes Software Engineering Internship Assignment**.

The project focuses on exploring and working with **real-estate data through the APIs provided by Ivy Homes**, with **Pune** as the assigned city and **Baner** as the assigned locality.

## Overview

The application is designed around the assignment requirements provided by Ivy Homes. It involves interacting with the given APIs, retrieving relevant locality and property information, and presenting the processed results through a simple and intuitive interface.

The primary objective was to understand the provided API ecosystem, correctly handle the required data, and implement the workflows specified in the assignment.

## Key Highlights

- Integration with the APIs provided by Ivy Homes
- Working with locality and property-related information
- Handling API requests and responses
- Processing and presenting the retrieved data
- Implementing the workflows and requirements specified in the assignment
- Focus on a clean and user-friendly interface

## Tech Stack

- **React**
- **Vite**
- **JavaScript**
- **REST APIs**
- **HTML & CSS**

## Objective

The objective of this assignment was to build a functional application based on the provided API specifications and demonstrate the ability to:

- Understand an existing API contract
- Work with real-world structured data
- Implement frontend workflows around API-driven functionality
- Handle data processing and presentation
- Build a clean and functional user experience
